# E-commerce Frontend Design - Internship Project 🚀

This repository contains the frontend implementation of a modern e-commerce platform, developed during my **Frontend Developer Internship at Developershub Corporation**. The project focuses on converting professional Figma designs into high-quality, pixel-perfect, and responsive web pages.

## 🌟 Project Overview

The goal of this internship was to build a fully functional and visually accurate e-commerce website. The design follows a clean, user-centric approach inspired by industry leaders like Alibaba and Amazon, focusing on clean UI and seamless UX.

## 📅 Internship Journey & Milestones

### ✅ Week 1: Foundation & Layout
- **Header & Navigation:** Designed a pixel-perfect Header with a functional search bar, category dropdown, and professional user action icons.
- **Footer Architecture:** Implemented a professional multi-column footer with social media integration, app links, and a language selector.
- **Typography:** Ensured consistent branding using the **Inter** font family.

### ✅ Week 2: Content & Structure
- **Hero Section:** Built a dynamic main banner with a category sidebar and user-specific call-to-action cards.
- **Deals & Offers:** Implemented a "Deals and Offers" section featuring a countdown timer and product grid.
- **Category Blocks:** Created organized blocks for "Home & Outdoor" and "Consumer Electronics" with side banners and product grids.

### ✅ Week 3: Interaction & Optimization
- **Full Page Suite:** Developed the **Product Listing**, **Product Detail**, and **My Cart** pages to complete the user flow.
- **Responsive Design:** Used CSS Grid and Flexbox to make the entire site 100% responsive for Mobile, Tablet, and Desktop.
- **JavaScript Interactivity:** Integrated JS for search alerts, size selection, and DOM manipulation to enhance user engagement.
- **Git Workflow:** Managed the project lifecycle using Git, including repository management and clean commit history.

## 🛠️ Tech Stack

* **HTML5:** Semantic structure for better SEO and accessibility.
* **CSS3:** Advanced styling using Flexbox, CSS Grids, Custom Gradients, and Media Queries for responsiveness.
* **JavaScript (ES6):** Logic for UI interactivity and dynamic elements.
* **Figma:** Primary tool for design measurements and asset exports.
* **Git & GitHub:** Version control and project deployment.
